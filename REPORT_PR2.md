## 3. Индивидуальный проект
- **Название проекта:** «Система учета учебной нагрузки преподавателей» (*Academic Workload Manager*).
- **Перечень функций, реализованных на ПР2:**
  1. *Модуль `teachers.py`:* `add_teacher` (добавление в словарь с генерацией ID), `find_teachers` (поиск по подстроке ФИО/кафедры), `get_teacher` (получение данных), `filter_teachers_generator` / `filter_teachers_by_rate` (фильтрация по ставке через генератор), `sort_teachers` (сортировка списка по ФИО или ставке через `lambda`-функцию).
  2. *Модуль `workloads.py`:* `calculate_total_workload` (расчет суммы часов, из ПР1), `check_workload_compliance` (проверка нормы ставки, из ПР1), `calculate_actual_rate` (фактическая ставка, из ПР1), `calculate_plan_fulfillment_percent` (процент выполнения, из ПР1), `add_workload` (создание учебного поручения), `cancel_workload` (отмена/удаление поручения), `get_teacher_workloads` (выборка по преподавателю), `get_teacher_total_hours` (подсчет суммарных часов преподавателя).
  3. *Модуль `storage.py`:* `load_teachers`, `save_teachers`, `load_workloads`, `save_workloads` (чтение и запись данных с контекстным менеджером `with` и обработкой `FileNotFoundError` и `json.JSONDecodeError`).
  4. *Модуль `utils.py`:* `input_int`, `input_float`, `input_str` (безопасный ввод данных с циклом повторного запроса и перехватом `ValueError`).
  5. *Модуль `main.py`:* `show_teachers`, `show_workloads`, `show_teacher_workload_report` (детальная сводка с проверкой нормы ПР1), `main` (цикл меню `while True` с 10 пунктами действий).
- **Структура модулей проекта:**
  ```text
  academic-workload-manager/
  ├── main.py            # Точка запуска и пользовательский интерфейс
  ├── teachers.py        # Управление реестром преподавателей
  ├── workloads.py       # Расчет и распределение учебной нагрузки
  ├── storage.py         # Модуль сохранения и загрузки JSON-файлов
  ├── utils.py           # Вспомогательные функции валидации ввода
  ├── data/              # Каталог постоянного хранения данных
  │   ├── teachers.json  # Данные преподавателей
  │   └── workloads.json # Журнал учебных поручений
  └── tests/             # Каталог автоматических тестов
      ├── test_teachers.py
      └── test_workloads.py
  ```
- **Формат хранения данных:** JSON-файлы со списками словарей (`data/teachers.json`, `data/workloads.json`), кодировка UTF-8, форматирование с отступами.
