## 3. Индивидуальный проект
- **Название проекта:** «Система учета учебной нагрузки преподавателей» (*Academic Workload Manager*).
- **Перечень функций, реализованных на ПР2:**
  1. *Модуль `teachers.py`:* `add_teacher` (добавление преподавателя в словарь с автоматической генерацией ID), `find_teachers` (поиск по подстроке ФИО или кафедры), `get_teacher` (получение данных по ID), `filter_teachers_by_rate` (фильтрация преподавателей по минимальной ставке с применением генератора), `sort_teachers` (сортировка по ФИО или ставке с использованием `lambda`-функции в качестве ключа).
  2. *Модуль `workloads.py`:* `calculate_total_workload` (расчет суммы аудиторных и внеаудиторных часов, развито из ПР1), `check_workload_compliance` (проверка нормы часов ставки с учетом допуска погрешности, из ПР1), `calculate_actual_rate` (вычисление фактически выработанной ставки, из ПР1), `calculate_plan_fulfillment_percent` (процент выполнения годовой нормы, из ПР1), `add_workload` (создание учебного поручения), `cancel_workload` (отмена/удаление поручения по ID), `get_teacher_workloads` (выборка поручений преподавателя), `get_teacher_total_hours` (суммирование часов нагрузки преподавателя).
  3. *Модуль `storage.py`:* `load_teachers`, `save_teachers`, `load_workloads`, `save_workloads` (чтение и сохранение данных в формате JSON с использованием контекстного менеджера `with` и обработкой исключений `FileNotFoundError` и `json.JSONDecodeError`).
  4. *Модуль `utils.py`:* `input_int`, `input_float`, `input_str` (безопасный ввод чисел и строк с циклом повторного запроса и перехватом `ValueError`).
  5. *Модуль `main.py`:* `show_teachers`, `show_workloads`, `show_teacher_workload_report` (формирование детального отчета с проверкой нормы ПР1), `main` (цикл консольного меню `while True` с 10 пунктами действий).
- **Структура модулей проекта:**
  ```text
  academic-workload-manager/
  ├── main.py            # Точка запуска и пользовательский интерфейс
  ├── teachers.py        # Управление реестром преподавателей
  ├── workloads.py       # Расчет и распределение учебной нагрузки
  ├── storage.py         # Модуль сохранения и загрузки JSON-файлов
  ├── utils.py           # Вспомогательные функции валидации ввода
  ├── data/              # Каталог постоянного хранения данных
  │   ├── teachers.json  # Данные преподавателей
  │   └── workloads.json # Журнал учебных поручений
  └── tests/             # Каталог автоматических тестов
      ├── test_teachers.py
      └── test_workloads.py
  ```
- **Формат хранения данных:** JSON-файлы со списками словарей (`data/teachers.json`, `data/workloads.json`), кодировка UTF-8, форматирование с отступами `indent=2`.
