## 3. Доработка индивидуального проекта
- **Название проекта:** «Система учета учебной нагрузки преподавателей» (Academic Workload Manager).
- **Архитектура веб-приложения на базе Django 5.2:**
  1. **Конфигурационный проект `workload_manager`:** файл `settings.py` (локализация `ru-RU`, часовой пояс `Europe/Moscow`, регистрация приложений), корневая маршрутизация `urls.py` с подключением дочерних `urls` через функцию `include()` и регистрация кастомного обработчика `handler404 = "homepage.views.page_not_found"`.
  2. **Приложение `homepage`:** главная визитная страница (`/`), описание возможностей системы, карточки быстрого перехода, базовый шаблон Bootstrap 5.3 CDN (`page()`), а также централизованный обработчик ошибки 404 (`page_not_found()`).
  3. **Приложение `teachers`:** список преподавателей кафедры (`/teachers/`) с расчетом выполнения индивидуальной нормы и бейджами статуса; детальная страница преподавателя (`/teachers/<int:teacher_id>/`) с плановой нормой, фактической ставкой, процентом выполнения и реестром закрепленных поручений. При отсутствии преподавателя возвращается HTTP 404.
  4. **Приложение `workloads`:** общий реестр учебных поручений (`/workloads/`) со сводкой часов и статусами; детальная карточка поручения (`/workloads/<int:workload_id>/`) с разбивкой по лекциям, практикам, лабораториям, экзаменам и прямыми ссылками на преподавателя. При отсутствии поручения возвращается HTTP 404.
- **Сохранение кодовой базы ПР3:**
  - Полностью сохранены доменные классы ООП (`Teacher`, `Discipline`, `Workload` в пакете `models/`).
  - Сохранены функции загрузки и сохранения в JSON (`storage.py`) с восстановлением объектных связей.
  - Сохранено и полностью работоспособно интерактивное консольное приложение (`main.py`).
  - В модуль `models/workloads.py` добавлена функция `find_workload_by_id` для эффективного поиска поручения по первичному ключу.
- **Ссылка на Git-репозиторий:** https://github.com/Fryzux/academic-workload-manager

## 4. Результат работы
В результате выполнения практической работы № 5:
- **Развернут веб-каркас Django 5.2:** инициализирован проект `workload_manager` и созданы 3 тематических приложения (`homepage`, `teachers`, `workloads`);
- **Реализована гибкая маршрутизация URL:** настроены пути для главной страницы, списков и детальных карточек сущностей с использованием целочисленных конвертеров параметров;
- **Разработаны функции-представления (views):** все представления принимают `HttpRequest`, загружают данные предметной модели и формируют валидный `HttpResponse` с кодами 200 OK или 404 Not Found;
- **Интегрирован современный пользовательский интерфейс:** применен Bootstrap 5.3 CDN с адаптивной сеткой, навигационной панелью, информационными карточками, таблицами и цветовой индикацией выполнения учебной нормы;
- **Реализована обработка ошибок:** внедрена страница 404 с кастомным представлением и навигацией;
- **Расширен комплекс автоматизированного тестирования:** в модуле `tests/test_views.py` реализованы тесты для веб-представлений с использованием `django.test.Client`. Общее количество тестов достигло 25 (все 25 успешно пройдены);
- **Обеспечена чистота кода:** проект полностью соответствует стандарту PEP 8 (`flake8` без предупреждений и ошибок при лимите 79 символов).
