# Система учета учебной нагрузки преподавателей (Academic Workload Manager)

Веб-приложение на базе **Django 5.2** и консольное объектно-ориентированное приложение для автоматизации процессов планирования, учета, анализа и контроля учебной нагрузки преподавателей кафедры высшего учебного заведения.

Разработано в рамках практических работ №1–№5 по дисциплине «Технологии разработки приложений на базе фреймворков» (РТУ МИРЭА).
Тема проекта № 488: «Система учета учебной нагрузки преподавателей».

## Возможности системы

### Веб-интерфейс (Django 5.2 + Bootstrap 5.3 CDN)
- Главная визитная страница с описанием функционала системы (`/`).
- Список преподавателей кафедры с отображением занимаемых ставок, фактических часов и бейджей соблюдения нормы (`/teachers/`).
- Детальная карточка преподавателя с индивидуальным расчетом плановой нормы, фактической ставки, процента выполнения плана и таблицей закрепленных поручений (`/teachers/<id>/`).
- Список всех учебных поручений с разбивкой по видам учебной работы (лекции, практики, лабы, экзамены) и статусам (`/workloads/`).
- Детальная карточка учебного поручения с информацией о преподавателе, дисциплине и академических часах (`/workloads/<id>/`).
- Кастомная страница ошибки 404 с удобной навигацией (`homepage.views.page_not_found`).

### Консольный интерфейс (ООП-модуль ПР3)
- Полнофункциональное меню (`python main.py`).
- Поиск, сортировка с `lambda`-функцией, генераторная фильтрация по ставке.
- Создание преподавателей, дисциплин и учебных поручений с валидацией.
- Отмена и восстановление поручений без потери истории.
- Форматированный консольный отчет о нагрузке преподавателя.

### Хранилище данных
- Постоянное хранение данных в формате JSON (`data/teachers.json`, `data/disciplines.json`, `data/workloads.json`).
- Автоматическое восстановление объектных связей между поручениями, преподавателями и дисциплинами при загрузке.

## Требования
- Python 3.10+ (протестировано на Python 3.14)
- Django 5.2.*
- pytest >= 8.0
- flake8 >= 7.0
- python-docx >= 1.0

## Установка и запуск

### 1. Клонирование и настройка окружения
```powershell
git clone https://github.com/Fryzux/academic-workload-manager.git
cd academic-workload-manager
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 2. Запуск веб-сервера Django
```powershell
python manage.py migrate
python manage.py runserver
```
После запуска веб-приложение доступно в браузере по адресу: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)

### 3. Запуск консольного приложения
```powershell
python main.py
```

### 4. Запуск автоматических тестов
```powershell
pytest -v
```

### 5. Проверка качества кода линтером (PEP 8)
```powershell
flake8 --max-line-length=79 --exclude=.venv,*/migrations/*
```
