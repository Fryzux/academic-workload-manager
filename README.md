# Система учета учебной нагрузки преподавателей (Academic Workload Manager)

Консольное приложение для автоматизации процессов планирования, учета, анализа и контроля учебной нагрузки преподавателей кафедры высшего учебного заведения.

## Возможности
- просмотр полного списка преподавателей и закрепленной за ними нагрузки;
- контекстный поиск преподавателей по ФИО и названию кафедры;
- сортировка списка преподавателей по ФИО (по алфавиту) и по ставке (по убыванию) с использованием `lambda`-функции;
- фильтрация преподавателей по минимальной ставке с применением генератора;
- добавление новых преподавателей с валидацией входных данных;
- назначение и распределение учебной нагрузки по дисциплинам и видам занятий (лекции, практики, лабораторные, экзамены);
- формирование детального индивидуального отчета преподавателя с расчетом выполнения нормы нагрузки (перенос и развитие логики ПР1);
- отмена и удаление ошибочно назначенных учебных поручений;
- постоянное хранение данных в JSON-файлах с автосохранением и обработкой ошибок ввода-вывода.

## Структура проекта
- `main.py` – точка запуска приложения, организация консольного меню и табличного вывода;
- `teachers.py` – логика работы с преподавателями (структуры-словари, генераторы, `lambda`-сортировка);
- `workloads.py` – расчет нагрузки, проверка соответствия ставке (из ПР1), добавление и отмена поручений;
- `storage.py` – модуль сохранения и загрузки данных JSON с использованием контекстного менеджера `with`;
- `utils.py` – функции безопасного ввода данных пользователем с обработкой исключений (`try / except`);
- `data/` – каталог с файлами данных в формате JSON:
  - `data/teachers.json` – реестр преподавателей кафедры;
  - `data/workloads.json` – журнал распределения учебной нагрузки;
- `tests/` – пакет автоматизированных модульных тестов:
  - `tests/test_teachers.py` – тестирование функций работы с преподавателями;
  - `tests/test_workloads.py` – тестирование расчетов и управления нагрузкой;
- `pytest.ini` – файл конфигурации тестовой среды;
- `requirements.txt` – перечень зависимостей проекта (`pytest`, `flake8`, `python-docx`).

## Требования
- Python 3.10+
- pytest >= 8.0
- flake8 >= 7.0

## Установка зависимостей
```powershell
pip install -r requirements.txt
```

## Запуск приложения
```powershell
python main.py
```

## Запуск тестов
```powershell
pytest -v
```

## Проверка качества кода (линтер)
```powershell
flake8 --max-line-length=79 --exclude=.venv
```
