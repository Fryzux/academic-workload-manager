# Система учета учебной нагрузки преподавателей (Academic Workload Manager)

Консольное объектно-ориентированное приложение для автоматизации процессов планирования, учета, анализа и контроля учебной нагрузки преподавателей кафедры высшего учебного заведения.

## Возможности
- просмотр перечней преподавателей, учебных дисциплин и закрепленной нагрузки;
- поиск преподавателей по ФИО и названию кафедры;
- сортировка списка преподавателей по ФИО и ставке с использованием `lambda`-функции;
- фильтрация преподавателей по минимальной ставке с применением генератора;
- создание новых преподавателей и учебных дисциплин с валидацией данных;
- распределение учебной нагрузки с прямым связыванием объектов `Teacher` и `Discipline`;
- расчет выполнения нормы нагрузки преподавателя с учетом допустимой погрешности (алгоритмы ПР1/ПР2);
- отмена и восстановление учебных поручений через методы объекта без потери истории;
- постоянное хранение данных в JSON-файлах с автоматическим восстановлением объектных связей.

## Целевая аудитория
Преподаватели, заведующие кафедрами и специалисты учебно-методического управления вуза.

## Объектная модель и основные классы

### 1. `Teacher` (Преподаватель)
Представляет сотрудника кафедры.
- **Основные атрибуты:**
  - `id` — уникальный идентификатор;
  - `name` — фамилия, имя и отчество;
  - `position` — должность (доцент, профессор, ассистент и др.);
  - `department` — название кафедры;
  - `rate` — занимаемая ставка по трудовому договору (0.1..2.0).
- **Основные методы:**
  - `__init__()` — инициализация объекта;
  - `__str__()` — строковое представление преподавателя;
  - `from_data(data)` — метод класса (`@classmethod`) создания из словаря JSON;
  - `validate_rate(rate)` — статический метод (`@staticmethod`) валидации ставки;
  - `calculate_planned_hours(standard_full_rate_hours)` — расчет годовой нормы часов;
  - `to_dict()` — сериализация в словарь для JSON.

### 2. `Discipline` (Учебная дисциплина)
Представляет преподаваемый предмет.
- **Основные атрибуты:**
  - `id` — уникальный идентификатор;
  - `name` — наименование дисциплины;
  - `department` — закрепляющая кафедра;
  - `semester` — номер семестра (1..12).
- **Основные методы:**
  - `__init__()` — инициализация объекта;
  - `__str__()` — строковое представление дисциплины;
  - `from_data(data)` — метод класса (`@classmethod`) создания из словаря JSON;
  - `validate_semester(semester)` — статический метод валидации семестра;
  - `to_dict()` — сериализация в словарь для JSON.

### 3. `Workload` (Учебное поручение)
Связывает объект преподавателя `Teacher` и объект дисциплины `Discipline`.
- **Основные атрибуты:**
  - `id` — уникальный идентификатор поручения;
  - `teacher` — ссылка на связанный объект `Teacher`;
  - `discipline` — ссылка на связанный объект `Discipline`;
  - `lectures` — объем часов лекций;
  - `practices` — объем часов практических занятий;
  - `labs` — объем часов лабораторных работ;
  - `exams` — объем часов консультаций и экзаменов;
  - `is_cancelled` — признак отмены поручения.
- **Основные методы и свойства:**
  - `@property total_hours` — вычисление суммарного объема часов;
  - `@property status` — строковый статус («Активно» / «Отменено»);
  - `cancel()` — отмена поручения (изменение состояния без удаления объекта);
  - `restore()` — восстановление поручения;
  - `to_dict()` — сериализация (сохранение `teacher_id` и `discipline_id`);
  - `__str__()` — строковое описание поручения.

## Взаимодействие объектов
```text
Workload
  ├── teacher    ──> Teacher (доступны workload.teacher.name, workload.teacher.rate)
  └── discipline ──> Discipline (доступны workload.discipline.name, workload.discipline.semester)
```

## Структура проекта
```text
academic-workload-manager/
├── main.py            # Точка запуска приложения, главное меню и пользовательские сценарии
├── storage.py         # Модуль сохранения и загрузки объектов в формате JSON
├── utils.py           # Вспомогательные функции безопасного ввода данных
├── models/            # Пакет классов предметной области
│   ├── __init__.py    # Экспорт классов Teacher, Discipline, Workload
│   ├── teachers.py    # Класс Teacher и функции работы с коллекцией List[Teacher]
│   ├── disciplines.py # Класс Discipline и функции работы с коллекцией List[Discipline]
│   └── workloads.py   # Класс Workload и функции расчетов List[Workload]
├── data/              # Хранилище данных приложения в формате JSON
│   ├── teachers.json  # Реестр преподавателей
│   ├── disciplines.json # Реестр учебных дисциплин
│   └── workloads.json # Журнал учебных поручений (связи по ID)
├── tests/             # Пакет автоматизированных тестов
│   ├── test_teachers.py    # Тесты класса Teacher и его методов
│   ├── test_disciplines.py # Тесты класса Discipline и его методов
│   └── test_workloads.py   # Тесты класса Workload, связей и расчетов
├── pytest.ini         # Конфигурация тестовой среды
└── requirements.txt   # Зависимости проекта (pytest, flake8, python-docx)
```
