## 4. Доработка индивидуального проекта
- **Структура каталогов шаблонов:** В корне проекта создан каталог `templates/`, зарегистрированный в `workload_manager/settings.py` через `TEMPLATES[0]['DIRS'] = [BASE_DIR / 'templates']`. Внутри каждого приложения созданы изолированные каталоги шаблонов (`homepage/templates/homepage/`, `teachers/templates/teachers/`, `disciplines/templates/disciplines/`, `workloads/templates/workloads/`).
- **Базовый шаблон (`templates/base.html`):** Определяет каркас HTML5, содержит блок мета-тегов, заголовка `{% block title %}`, подключение Bootstrap 5.3 CDN, кастомных стилей `homepage/css/style.css`, шапку с логотипом `homepage/img/logo.png`, центральный блок `{% block content %}` и подвал со скриптом `homepage/js/main.js`.
- **Включаемые шаблоны (`{% include %}`):**
  - `templates/includes/navigation.html`: адаптивное меню с ссылками на разделы сайта через именованные маршруты;
  - `teachers/templates/teachers/includes/teacher_card.html`: визуальная карточка преподавателя с расчетом нагрузки;
  - `workloads/templates/workloads/includes/workload_status.html`: цветовой бейдж статуса поручения.
- **Отказ от ручной генерации HTML:** Вспомогательная функция `page()` и ручная конкатенация HTML-строк в `HttpResponse` полностью устранены во всех представлениях. Все view-функции используют `django.shortcuts.render()`.
- **Контекст и теги DTL:** Данные предметной области передаются в виде словарей контекста; для итерации используется тег `{% for %}` с веткой `{% empty %}` для пустых коллекций; условная логика реализована тегами `{% if %}`, `{% elif %}`, `{% else %}`.
- **Именованные URL и пространства имен:** Во всех приложениях задана переменная `app_name` (`homepage`, `teachers`, `disciplines`, `workloads`). Все ссылки в шаблонах строятся с помощью тега `{% url 'namespace:name' %}`.
- **Фильтры шаблонов:** Применены фильтры `|length`, `|default`, `|floatformat` для форматирования числовых и строковых данных.
- **Статические файлы:** Настроен поиск статики (`STATIC_URL = 'static/'`), созданы файлы `homepage/static/homepage/css/style.css`, `homepage/static/homepage/js/main.js` и графический логотип `homepage/static/homepage/img/logo.png`.
- **Обработка ошибки 404:** Создан шаблон `templates/404.html`, расширяющий `base.html`, и представление `homepage.views.page_not_found`, возвращающее HTTP-код 404.
- **Сохранение кодовой базы:** Доменные модели ООП (`Teacher`, `Discipline`, `Workload`), JSON-хранилище (`storage.py`) и консольный интерфейс `main.py` полностью сохранены и работоспособны.
